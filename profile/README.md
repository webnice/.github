# WEB NICE

Набор открытых библиотек и инструментов на Go для построения серверных приложений:
от управляемых сетевых серверов и веб-сервисов до работы с базами данных,
справочников, типов данных и интеграций с внешними API. Все библиотеки
распространяются под лицензией MIT.

## Инфраструктура приложений

| Репозиторий | Описание |
|-------------|----------|
| [kit](https://github.com/webnice/kit) | Инструментарий для построения приложений: ядро с жизненным циклом, модули (конфигурация, логирование, БД, шина событий, файловое хранилище и др.), система плагинов. |
| [job](https://github.com/webnice/job) | Управление заданиями и горутинами: планировщик фоновых заданий, пул воркеров, события. |
| [run](https://github.com/webnice/run) | Запуск внешних приложений и взаимодействие с ними через STDIN, STDOUT, STDERR: буферы и каналы, сигналы, завершение через контекст, chroot. |

## Сетевые сервисы

| Репозиторий | Описание |
|-------------|----------|
| [net](https://github.com/webnice/net) | Управляемый сервер на базе стандартного пакета `net`: TCP, UDP, TLS, unix-сокеты, запуск через systemd-сокеты, поддержка proxy protocol v1/v2. |
| [web](https://github.com/webnice/web) | Микро-сборка управляемого веб-сервера на `net/http`: HTTP/2 и h2c, TLS, unix-сокеты, systemd, ограничение размера запроса. |
| [transport](https://github.com/webnice/transport) | Клиент для выполнения HTTP запросов с пулом соединений и пулом объектов запросов. |

## Данные и базы

| Репозиторий | Описание |
|-------------|----------|
| [d2s](https://github.com/webnice/d2s) | Генератор Go-структур по структуре таблиц MySQL/MariaDB (утилита `db2struct`): теги `db` и `gorm`, nullable-поля через типы `nix`. |
| [f8n](https://github.com/webnice/f8n) | Формирование SQL-запросов с фильтрацией, сортировкой, лимитами и постраничным выводом на основе параметров HTTP-запроса; интеграция с GORM. |
| [migrate](https://github.com/webnice/migrate) | Инструмент миграций базы данных на основе goose: инкрементные SQL-миграции и миграции на Go; mysql, postgres, sqlite3, clickhouse, tidb и др.; консольная утилита `gsmigrate`. |
| [nix](https://github.com/webnice/nix) | Типы данных-обёртки для значений, допускающих NULL: реализуют `sql.Scanner`, `driver.Valuer`, кодеки JSON, Text и Gob; совместимы с database/sql, GORM, sqlx. |
| [dic](https://github.com/webnice/dic) | Библиотека справочников: MIME-типы, HTTP-методы, заголовки, статусы ответов, расширения файлов, справочник ошибок с шаблонами и кодами. |
| [cpy](https://github.com/webnice/cpy) | Копирование объекта в объект с фильтрацией и конвертацией полей. |
